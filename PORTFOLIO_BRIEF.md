## Design direction
- The site is itself a work sample for the design track. It must not read as a template.
- Typographic, lots of whitespace, consistent grid, large high-quality images. Restrained, precise.
- Mobile-first. Loads in under 2 seconds. Images as WebP, lazy-loaded. Every image has alt text; contrast and keyboard navigation pass accessibility checks.
- No stock imagery, no carousels, no animation that delays content.

## Tech plan (beginner-friendly)
- **Static site** — plain files, no database, no server to manage.
- **Astro** as the framework: each case study is a Markdown file with frontmatter (`title`, `tracks`, `featured`, `order`, `date`, `outcome`) plus an images folder; it builds to plain HTML.
- **Filtering** — a small client-side script reads the `track` query parameter and shows matching cards; no framework needed.
- **Repo name must be exactly `mjzun.github.io`** so the site lives at the root URL. Claude Code creates it (public) and pushes; the GitHub command-line tool needs a one-time login.
- **Deploy** — a GitHub Actions workflow rebuilds and publishes on every push to `main`.
- **Custom domain later** — buy a domain, add a CNAME file, same site serves both.
